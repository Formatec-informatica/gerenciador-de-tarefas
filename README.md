# gerenciador-de-tarefas
Gerencia as tarefas do Windows, várias funções em um aplicativo personalizado, criado especificamente para técnicos e para quem gosta de explorar as possibilidades e a criatividade.

## Download

A versão mais recente fica na pasta [`versao`](versao):

- **Instalador_Gerenciador_de_Tarefas.exe** — instala ou atualiza o programa.
- **Gerenciador_de_Tarefas_Portatil.exe** — versão portátil (um arquivo só, sem instalar).

Os programas instalados se atualizam sozinhos pelo arquivo [`atualizacao.json`](atualizacao.json), que traz a versão, os endereços e o SHA-256 de cada arquivo.
